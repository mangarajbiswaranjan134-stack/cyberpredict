## 3. Google Stitch Entity & Cashout Flow Canvas

The **Stitch Canvas** tab implements modern Google Stitch software canvas principles:

  $$\text{Citizen Victim} \longrightarrow \text{Mobile/IMEI} \longrightarrow \text{Layer-1 Mule} \longrightarrow \text{Layer-2 Aggregator} \longrightarrow \text{Target ATM Node} \longrightarrow \text{Cell Tower}$$
- **Forensic Hop Velocity**: Tracks transfer time across banking layers (averaging 3.8 to 4.2 minutes per hop) to calculate the remaining intercept countdown window.
- **1-Click Rapid Statutory Triggers**: Instant buttons on any graph node to execute Section 102 BNSS freezes or 112 Emergency patrol dispatches.
